bananaShell

Privacy Policy

This policy describes how bananaShell for macOS, developed by Howon Kim, handles your information.

Terminal Sessions and Local Storage

bananaShell runs your shells on your Mac through its own tmux server. Terminal output, scrollback, window layouts, automation recordings and logs, prompt settings and preferences are stored on your Mac. Automation logs are kept in ~/Library/Logs/bananaShell/. bananaShell does not have an account system and does not send your terminal contents to us.

Keys

SSH keys you generate are saved as files on your Mac. API key values you add are stored in your local macOS Keychain and are excluded from search. bananaShell does not upload these keys.

Claude Code Alerts

When you use Claude Code in a bananaShell terminal, bananaShell can show a completion alert with a short preview of Claude's final reply. The preview is written to an owner-only file on your Mac and deleted as soon as the app reads it. Your conversations with Claude are handled by Anthropic under its own privacy policy; bananaShell does not send them anywhere.

Network Access

Release builds check GitHub for updates and download them from GitHub Releases. When you choose to install optional prompt tools, such as Homebrew, Oh My Posh, Starship or shell plugins, bananaShell downloads them from their publishers. GitHub and these providers receive standard request information, such as your IP address, under their own privacy policies. The commands you run in the terminal connect wherever you direct them.

Notifications and Permissions

bananaShell asks for notification permission to show alerts and badge counts. macOS may ask for other permissions when commands you run access protected folders or apps. You can change these in System Settings.

Retention and Deletion

Closing a terminal ends its session. You can delete automations and keys in the app, and remove app data by deleting bananaShell and its folders in ~/Library/Application Support/bananaShell/ and ~/Library/Logs/bananaShell/. API keys can also be removed with Keychain Access.

Open Source

bananaShell's source code is public, so you can review how it handles data.

Contact

If you have questions about this policy, visit bananaShell Support or email feedback@decultureware.com.
