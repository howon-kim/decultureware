bananaShell Support

We'd love to hear from you! If you have any questions, suggestions, or feedback about bananaShell, please don't hesitate to reach out.

The bananaShell guide covers every feature and shortcut. bananaShell keeps sessions in tmux; if you downloaded the disk image, install it with brew install tmux. Please include your macOS and bananaShell versions when reporting an issue.

You can also report bugs or request features in GitHub Issues. Issues are public, so do not include private information.
